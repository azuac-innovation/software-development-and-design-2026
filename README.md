# software-development-and-design-2026

# I. Müqəddimə
Bu tədris planı ali təhsilin maqistr pilləsində əyani təhsil alan tələbələrə “Proqram təminatının inkişafı və dizaynı” fənninin tədrisi üçün işlənib hazırlanmışdır. Sillabus fənnin fənn proqramı əsasında tərtib edilmişdir.
Fənn auditoriyalarda mühazirələrin  oxunması, praktik  məşğələlərin  aparılması və tələbələrə fənni tədris edən müəllim tərəfindən verilən mövzular üzrə sərbəst işlərin yerinə yetirilməsi yolu ilə öyrənilir. 
“Proqram təminatının inkişafı və dizaynı”fənn ilə proqram təminatının müasir inkişaf və dizayn prinsiplərini əhatə edir. Fənn çərçivəsində proqram təminatının hazırlanmasına giriş, müasir inkişaf yanaşmaları, tələblərin formalaşdırılması və biznes təhlili, UML vasitəsilə sistem modelləşdirilməsi və proqram təminatı arxitekturasının qurulması öyrədilir. UI/UX dizayn prinsipləri, çevik metodologiyalar (Agile, Scrum), DevOps mədəniyyəti və avtomatlaşdırma prosesləri praktik yanaşma ilə izah olunur.

# II. Fənninin öyrənilməsinin məqsədi
Bu fənnin öyrənilməsinin məqsədi tələbələrə proqram təminatının müasir inkişaf və dizayn prinsiplərini, sistemli düşünmə və analitik yanaşmaları mənimsətmək, proqram təminatının həyat dövrünün bütün mərhələləri üzrə bilik və bacarıqlar qazandırmaqdır. Fənn tələblərin təhlili, arxitektura və sistem dizaynı, UI/UX prinsipləri, çevik metodologiyalar, DevOps yanaşmaları, bulud texnologiyaları, təhlükəsizlik, süni intellekt tətbiqləri və biznes dəyərinin yaradılması sahələrində tələbələrin nəzəri və praktik səriştələrini inkişaf etdirməyi hədəfləyir.

# Fənn üzrə bilik və bacarıqlara olan tələblər.
## Fənnin öyrənilməsi nəticəsində tələbələr aşağıdakıları bilməlidirlər:
•  Proqram təminatının həyat dövrü və müasir inkişaf yanaşmaları haqqında anlayış;
•  Tələblərin formalaşdırılması, biznes təhlili və maraqlı tərəflərlə iş prinsipləri;
•  UML diaqramları və sistem modelləşdirmə əsasları;
•  Proqram təminatı arxitekturası, dizayn nümunələri (design patterns) və sistem dizaynı prinsipləri;
•  UI/UX dizaynın əsas anlayışları və istifadəçi yönümlü dizayn prinsipləri;
•  Çevik metodologiyalar, Scrum çərçivəsi və DevOps mədəniyyəti;
•  Bulud hesablamaları və bulud əsaslı proqram təminatı inkişafı modelləri;
•  API inkişafı, inteqrasiya üsulları və mikroservis yanaşması;
•  Məlumat arxitekturası, məhsul analitikası və qərarvermə mexanizmləri;
•  Proqram təminatında süni intellekt və maşın öyrənməsi tətbiqlərinin əsasları;
•  Təhlükəsizlik prinsipləri və təhlükəsiz proqram təminatı dizaynı;
•  Məhsul idarəetməsi, rəqəmsal innovasiya və proqram təminatı iqtisadiyyatı anlayışları;
•  İT layihələrinin idarə edilməsi və risklərin nəzarəti metodları.

## Fənni öyrənən tələbələr aşağdakıları bacarmalıdırlar:
•  Proqram təminatı layihələri üçün funksional və qeyri-funksional tələbləri müəyyənləşdirmək;
•  UML vasitəsilə sistem və proses modelləri hazırlamaq;
•  Effektiv və miqyaslana bilən proqram təminatı arxitekturası dizayn etmək;
•  UI/UX dizayn prinsiplərini tətbiq edərək istifadəçi yönümlü interfeyslər hazırlamaq;
•  Agile və Scrum çərçivəsində komanda ilə işləmək və sprint proseslərini idarə etmək;
•  CI/CD, avtomatlaşdırma və DevOps alətlərindən istifadə etmək;
•  API-ləri dizayn etmək və sistemlərarası inteqrasiyanı həyata keçirmək;
•  Bulud mühitində tətbiqlərin yerləşdirilməsi və idarə olunması;
•  Məlumatlara əsaslanan qərarlar vermək və məhsul analitikası aparmaq;
•  Proqram təminatında təhlükəsizlik risklərini müəyyənləşdirmək və qarşısını almaq;
•  İT layihələrində riskləri təhlil etmək və idarə etmək;
•  Proqram təminatı layihələrində biznes dəyəri yaratmaq və innovativ həllər təklif etmək.
